## 仓库边界

- Git保存Markdown文档、机器可读元数据、配置、源代码、轻量模型和可复现测试资料。
- 大型STEP、系统镜像、训练数据、视频和长日志保存在外部存储，并在项目资产清单中记录位置与SHA-256。
- 日期快照必须同时提供ZIP、manifest和SHA-256；快照不等同于硬件、策略或验收已通过。
- 未经实测确认的协议、力矩控制、FOC和执行器能力必须明确标记为待验证。

## 推荐阅读顺序

1. 进入具体项目的`README.md`查看当前阶段和边界。
2. 阅读`project.json`获取机器可读状态。
3. 按`docs/`中的阶段顺序推进。
4. 通过验收文档和归档清单判断结果是否可复现。
