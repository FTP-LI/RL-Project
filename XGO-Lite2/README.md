# XGO Lite2

XGO Lite2是本工作区的唯一机器人本体项目。目标不是停留在原厂演示，而是把一台带CM4、摄像头、12自由度四足、机械臂和夹爪的桌面机器人逐步改造成可测量、可仿真、可训练、可由H7MS-Core-A1接管的低成本移动操作平台。

## 固定技术路线

```text
原厂整机验收
  → 原厂控制与数据基线
  → STEP数字孪生
  → URDF/MJCF模型
  → 高层策略与移动抓取
  → H7MS-Core-A1旁路监测
  → H7MS-Core-A1接管关节总线
```

开发期固定分工：

| 层级 | 职责 |
| --- | --- |
| RTX 3080 16GB、64GB内存笔记本 | MuJoCo/MJX训练、数据处理、视觉模型和开发期推理 |
| 原装CM4 | 相机、屏幕、网络、原厂程序和首阶段真机接口 |
| 原装下位机 | 首阶段步态、IMU、关节通信和安全回退基线 |
| H7MS-Core-A1 | 后续实时通信、时间戳、状态估计、安全状态机和关节调度 |
| 智能舵机 | 保留内部位置闭环；是否支持电流/温度/PID等扩展能力以实测为准 |

## 项目边界

- 第一目标是稳定复现原厂运动和抓取能力，再开展模型与学习工作。
- 第一版策略输出速度、姿态、步态参数或受限关节位置，不假设存在直接力矩接口。
- 真机不进行无安全约束的在线强化学习。
- 持续学习采用“记录失败—人工纠正—离线重训—固定回归集评估—受控部署”。
- H7MS-Core-A1不能阻塞原厂系统、数字孪生和高层策略阶段。
- 在协议、线束和电平未确认前，不拆除或替换原装下位机。
