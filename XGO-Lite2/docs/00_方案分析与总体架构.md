# 方案分析与总体架构

## 1. 项目定位

XGO Lite2的价值是把四足移动、视觉感知和简单抓取集中在一个低成本实体上。它不是准直驱四足，也不是六自由度工业机械臂；项目重点是建立完整的数据与控制闭环，而不是用营销自由度代替可测量能力。

适合研究：

- 四足运动学、状态估计和高层运动策略。
- 视觉跟踪、目标接近和简单移动抓取。
- 关节位置策略、模仿学习和受约束强化学习。
- 数字孪生、系统辨识、延迟建模和sim-to-real。
- 原厂下位机与H7MS-Core-A1控制链的一致性比较。

暂不承诺：

- 直接关节力矩控制或FOC。
- 高频阻抗控制和高冲击跳跃。
- 任意六维末端姿态或精细装配。
- 无人监管的真机在线探索。

## 2. 为什么选择Lite2

与只有四足本体的教学平台相比，Lite2额外提供机械臂和夹爪，可形成“观察—接近—抓取—搬运”的完整任务。现有完整STEP又使正确的Lite2几何模型可以自行重建，不再依赖错误的Mini2 URDF。

主要代价：

- CM4算力有限，训练必须放在笔记本。
- 原厂下位机和舵机内部固件不完全开放。
- STEP只有几何和装配关系，动力学参数仍需测量。
- 机械臂能力有限，必须把任务设计在其可达空间和负载范围内。

## 3. 最终系统架构

```text
训练与开发工作站
  MuJoCo/MJX、PyTorch、数据集、视觉、评估
                    │ 策略/配置/日志
                    ▼
上位计算层
  CM4首阶段；必要时外接树莓派4B或笔记本
  相机、任务状态机、策略推理、ROS2桥接
                    │ 带序号和时间戳的命令
                    ▼
实时控制层
  原厂下位机基线 → H7MS-Core-A1 + H7MS-XGOBase-A1
  IMU、状态估计、限位、看门狗、关节总线
                    │ 受限关节目标
                    ▼
执行器与机构
  12个腿部关节 + 机械臂/夹爪 + 足端接触
```

## 4. 控制分级

| 级别 | 策略输出 | 用途 | 启用条件 |
| --- | --- | --- | --- |
| L0 | 前进、横移、转向、姿态、预设动作 | 快速建立真机闭环 | 原厂接口稳定 |
| L1 | 足端目标、机械臂目标、夹爪命令 | 移动抓取和行为策略 | 坐标系与限位完成 |
| L2 | 受限关节位置目标 | 四足位置策略和sim-to-real | 同步反馈与延迟测量通过 |
| L3 | 电流/力矩或阻抗目标 | 研究型低层控制 | 只有舵机协议和硬件实测确认后才立项 |

L3不是默认目标。任何无法从实测或协议确认的能力都标记为TBD。

## 5. 安全原则

- 所有首次关节测试均在悬空、低速、小角度和限流条件下进行。
- 原装控制板与H7MS-Core-A1不得同时驱动同一半双工总线。
- 关节命令必须包含超时；上位机断联后进入保持或卸载状态。
- 机械臂伸出时限制四足速度和身体姿态。
- 训练策略外始终包裹独立的限位、变化率限制和故障状态机。
- 电池、舵机温度和通信错误必须进入日志并触发降级。

## 6. 阶段闸门

只有前一阶段验收通过，下一阶段才允许增加风险：

```text
整机无故障
→ 原厂接口可重复
→ 数字模型与真机一致
→ 仿真策略通过回归
→ 原厂链路低速部署
→ H7旁路监测
→ 单舵机接管
→ 全身悬空接管
→ 地面受控接管
```
