## 2. 资产处理规则

- 原始STEP只读保存，记录SHA-256，不覆盖、不重导出。
- Git中不提交来源或许可不明确的大型原始CAD。
- 导出的网格必须记录来源文件哈希、工具版本、单位和坐标变换。
- 视觉网格与碰撞网格分开；碰撞模型优先使用简单几何体。
- 螺钉、PCB元件、线束和装饰件不作为独立动力学连杆。

## 3. CAD清理

按以下顺序处理：

1. 确认STEP单位和总装坐标系。
2. 隐藏螺钉、电子元件和不影响外形的小零件。
3. 合并固定在一起的零件。
4. 将主体、12个腿部活动连杆、机械臂活动连杆和夹爪分组。
5. 在每个舵机输出轴中心建立关节坐标系。
6. 导出高质量视觉网格和低面数碰撞网格。

## 4. 关节树

统一关节树：

```text
base_link
├─ FL_hip → FL_thigh → FL_calf → FL_foot
├─ FR_hip → FR_thigh → FR_calf → FR_foot
├─ RL_hip → RL_thigh → RL_calf → RL_foot
├─ RR_hip → RR_thigh → RR_calf → RR_foot
└─ arm_joint1 → arm_joint2 → gripper
```

若CAD或实机证明机械臂还有独立旋转轴，则以实测更新关节树。营销自由度、API名称和实物轴数不一致时，以“一个独立可控旋转轴对应一个关节”为准。

## 5. URDF输出

URDF至少包含：

- `link`视觉、碰撞和惯量。
- `joint`原点、轴、限制、阻尼和摩擦初值。
- 统一的`base_link`、IMU、相机和足端坐标系。
- 实机舵机ID到URDF关节名的映射文件。
- 可在RViz中独立显示并通过`joint_state_publisher`扫描全部关节。

URDF不直接复制Mini2参数。Mini2只能作为命名和软件结构参考。

## 6. MJCF输出

MJCF在URDF几何基线上补充：

- 地面、重力、积分器和求解器配置。
- 足端接触体和摩擦参数。
- 关节阻尼、摩擦损失、臂端负载和执行器模型。
- IMU、关节位置、关节速度和接触传感器。
- 站立初始姿态、自由基座和安全关节限制。
- 原厂控制延迟、命令保持和观测噪声模型。

## 7. 质量与惯量

STEP几何不能自动保证真实材料和质量。初值来源按优先级排列：

1. 拆分称重和实物材料。
2. 厂商明确参数。
3. CAD体积乘以材料密度。
4. 对未知内部组件使用集中质量近似。

每个连杆记录参数来源和置信等级。最终通过摆动、静态姿态和简单步态日志校正，不为了拟合单个动作任意修改参数。

## 8. 验证闸门

- RViz外观、关节方向和实机一致。
- CAD测得的关键尺寸与实机误差有记录。
- 所有关节零位、限位和站立姿态一致。
- MuJoCo静止时无爆炸、穿透或持续能量增长。
- 固定关节姿态下，足端位置与实机测量一致。
- 原厂典型动作在仿真中能够以相同关节目标回放。
