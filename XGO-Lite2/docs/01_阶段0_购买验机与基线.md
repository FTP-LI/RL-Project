# 阶段0：购买验机与基线

目标是在退货窗口内确认整机、CM4、机械臂和所有关节可用，并保存后续改造前的恢复基线。

## 1. 付款前证据

要求卖家提供一段连续、不剪辑的视频：

1. 展示机身型号、序列号、舵机标签和配件。
2. 冷启动CM4并进入原厂界面。
3. 展示摄像头、屏幕、按键、扬声器和网络。
4. 完成站立、前后、横移、左右转向和身体姿态动作。
5. 逐个控制12个腿部关节。
6. 逐个控制机械臂关节并完整开合夹爪。
7. 读取IMU、电池、固件版本和全部关节角度。
8. 连续运行至少10分钟，再展示舵机温度、抖动、异响和重启情况。

## 2. 到货清单

| 类别 | 必查项目 |
| --- | --- |
| 本体 | 四腿、足垫、外壳、机械臂、夹爪、紧固件 |
| 计算 | CM4型号、内存、存储、TF卡、系统镜像、摄像头、屏幕 |
| 电气 | 电池、充电器、开关、充电口、原装下位机、线束 |
| 配件 | 手柄、数据线、包装、备用零件、说明资料 |
| 文件 | 原始系统镜像、固件、Python库、通信协议、校准数据 |

CM4信息至少保存以下输出：

```bash
cat /proc/device-tree/model
free -h
lsblk
uname -a
python3 --version
```

## 3. 到货测试顺序

```text
外观和电池检查
→ 不落地冷启动
→ 读取版本和传感器
→ 单关节小角度测试
→ 机械臂和夹爪
→ 悬空四足动作
→ 地面低速运动
→ 10分钟连续运行
→ 关机和再次冷启动
```

发现鼓包、焦味、破线、严重虚位或异常发热时停止上电。不得为了完成测试强行运行卡滞关节。

## 4. 改造前资产冻结

- 对整机六个方向、线束、接口和板卡拍照。
- 备份TF卡或CM4存储镜像并校验哈希。
- 记录原厂Python包版本和系统服务。
- 记录固件版本、关节ID、零位、正方向和角度限制。
- 保存原厂站立姿态与典型动作的关节角度日志。
- 测量整机、主体、机械臂和可拆零件质量。
- 保存原装板卡接插件针序，不依赖线色猜测。

## 5. 通过标准

- 12个腿部关节、机械臂和夹爪全部响应，无卡滞和打齿。
- 连续运行无异常复位、掉线和明显热衰减。
- CM4、摄像头、屏幕和存储工作正常。
- IMU、电池、固件和关节角度能够稳定读取。
- 原始系统和校准数据已有两份可恢复备份。
- 所有已知缺陷、配件缺失和维修历史写入验机记录。

阶段0未通过时，优先退货，不进入拆机、协议逆向或PCB设计。
