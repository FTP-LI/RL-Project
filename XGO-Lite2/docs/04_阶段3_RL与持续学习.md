# 阶段3：RL与持续学习

目标是先建立可评估的传统控制与模仿基线，再逐级增加策略自由度。训练在RTX 3080笔记本完成，CM4或外接上位机只做采集和推理。

## 1. 软件栈

| 模块 | 首选 |
| --- | --- |
| 动力学仿真 | MuJoCo；需要大规模并行时评估MJX |
| 训练 | PyTorch，算法与环境配置固定版本 |
| 日志 | TensorBoard或等价本地日志，原始数据保留 |
| 策略部署 | TorchScript或ONNX，部署前做数值一致性测试 |
| 视觉 | OpenCV基线，后续再接入轻量检测或视觉编码器 |

Isaac Sim只在需要更复杂视觉、传感器或第二物理环境交叉验证时引入，不作为阶段3的前置条件。

## 2. 先建立非学习基线

- 原厂速度和姿态控制。
- 固定轨迹与状态机。
- 机械臂坐标控制和夹爪阈值策略。
- 目标检测后按比例控制接近。
- 超时、失败恢复和人工急停。

学习策略必须与这些基线使用同一评测任务和日志格式。

## 3. 策略升级顺序

### 3A：高层运动策略

观测包括机体姿态、速度估计、目标方向和上一动作；输出限制为前后速度、横向速度、转向和身体高度。原厂下位机继续负责步态。

### 3B：受限关节位置策略

只有在12关节同步反馈和命令频率达到要求后启用。策略输出围绕安全站立姿态的小范围关节位置偏移，外层执行变化率限制和关节限位。

### 3C：移动抓取

将任务拆成可评估阶段：发现目标、接近、对准、伸臂、闭合夹爪、确认抓取、收臂和搬运。先用状态机和人工示范，再比较行为克隆或高层RL。

## 4. 数据记录

每个时间步至少保存：

- 单调时间戳和帧序号。
- 相机帧索引。
- 策略观测、原始传感器和归一化观测。
- 策略动作、安全层裁剪后的动作和最终发送命令。
- 关节角、IMU、电池和通信状态。
- 人工接管、急停、任务成功和失败原因。
- 软件版本、模型哈希和硬件配置。

视频、状态和动作必须能够重放对齐。仅保存成功片段会隐藏策略失效边界。

## 5. Sim-to-real

域随机化只围绕有根据的范围：

- 连杆质量和质心误差。
- 关节阻尼、摩擦和虚位。
- 地面摩擦。
- 控制延迟、丢包和命令保持。
- IMU偏置、噪声和安装误差。
- 电池电压导致的速度变化。

部署顺序固定为：离线回放、仿真回归、悬空、支撑架、低速地面、完整任务。任何阶段出现越界或异常热量都回退。

## 6. 持续学习闭环

```text
固定评测集
→ 受控部署
→ 自动记录失败和人工接管
→ 人工检查与补充示范
→ 离线重训
→ 仿真与历史数据回归
→ 小流量重新部署
```

模型不得在真机运行过程中自动替换权重。每个发布策略都有版本、训练数据范围、评测结果和回退版本。

## 7. 阶段验收

- 至少一个非学习基线和一个学习策略使用同一指标对比。
- 仿真和真机观测、动作定义完全一致。
- 策略在固定回归集上无安全违规。
- 真机连续运行可复现，日志能够定位每次失败。
- 移动抓取任务能够统计分阶段成功率，而不是只展示一次成功视频。
