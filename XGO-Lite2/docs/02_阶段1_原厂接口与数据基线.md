# 阶段1：原厂接口与数据基线

目标是不修改硬件，测清原厂上位机、下位机和舵机的能力边界，为数字孪生与H7MS-Core-A1接管提供可复现基线。

## 1. 软件环境冻结

- 记录系统镜像、内核、Python和`xgolib`版本。
- 建立最小独立脚本，不从原厂GUI内部直接复制业务逻辑。
- 每次实验保存配置、代码提交、固件版本和时间。
- 所有日志统一使用单调时钟，并记录上位机发送与收到反馈的时间戳。

## 2. 关节映射

逐关节发送约±5°目标，悬空确认：

| 字段 | 说明 |
| --- | --- |
| `joint_name` | 统一英文关节名 |
| `servo_id` | 原厂舵机编号 |
| `zero_raw` | 原始零位 |
| `direction` | 正方向，固定为+1或-1 |
| `min_deg/max_deg` | 安全角度范围 |
| `home_deg` | 默认站立或收臂姿态 |
| `bus/group` | 当前物理总线或逻辑分组 |

建议命名：`FL/FR/RL/RR`加`hip/thigh/calf`，机械臂使用`arm_joint1/arm_joint2/gripper`；若实机确认存在额外机械臂轴，再扩展，不预先假定。

## 3. 通信测量

分别测量以下操作的实际频率和延迟：

- 单关节写入。
- 多关节批量写入。
- 全部关节角读取。
- IMU读取。
- 高层移动命令。
- 机械臂目标与夹爪命令。
- 停止、卸载和断联恢复。

每项至少记录平均值、P95、最大值、超时率和连续运行错误数。API标称的超时时间不能代替实际更新率。

## 4. 原厂运动基线

保留以下参考实验：

1. 静态站立30秒。
2. 直线前进、后退和横移。
3. 原地左右旋转。
4. 身体高度、横滚和俯仰扫描。
5. 单腿小范围轨迹。
6. 机械臂工作空间扫描。
7. 夹爪空载与抓取轻物体。

同步记录命令、关节角、IMU、电池、视频和故障。相机帧与状态日志必须能按时间对齐。

## 5. 协议侦察

第一阶段只观察CM4与原装下位机通信：

- 确认UART端口、波特率、电平、帧头、长度、命令字和校验。
- 对照已知API操作建立数据包字典。
- 测量命令覆盖、限幅、平滑和看门狗行为。
- 不向未知寄存器写入，不执行未经验证的固件升级命令。

舵机原始总线侦察推迟到H7MS-Core-A1阶段，并要求逻辑分析仪高阻监听。

## 6. 通过标准

- 关节ID、零位、方向和安全限位表完整。
- 高频使用的写入与读取接口有实测时延统计。
- 原厂典型动作有同步状态和视频日志。
- 断联、停止、卸载和低电量行为已验证。
- 可以通过独立最小脚本稳定复现实验，不依赖手动GUI步骤。
