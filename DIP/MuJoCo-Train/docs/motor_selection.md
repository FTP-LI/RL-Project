# 电机选型：RS05 vs DM4310

你不需要照搬 Isaac Lab 项目里的 DM4310。

对二阶圆周倒立摆来说，真正重要的是这些参数：

```text
峰值力矩
持续力矩
最大转速
控制频率
控制模式
转子/输出端惯量
减速比
摩擦
延迟
CAN 通信协议
```

只要 RS05 的力矩、速度和控制频率够用，就可以先用 RS05 做第一版。

## 推荐做法

不要把电机型号写死在代码里。使用电机配置文件：

```text
hardware/motors/rs05.json
```

仿真环境从配置里读取：

```text
simulation.torque_limit_nm
```

这样以后如果你换 DM4310、其他灵足电机、或者自制驱动，只需要新建一个电机配置：

```text
hardware/motors/dm4310.json
hardware/motors/other_motor.json
```

再在实验配置里改：

```json
"motor_profile": "hardware/motors/rs05.json"
```

## 当前建议

第一阶段先保守一点：

```text
torque_limit_nm = 2.0
torque_response_time_s = 0.02
```

不要一开始就把力矩开很大。倒立摆在真实硬件上很容易因为控制器不稳定而撞限位。

## 需要你确认的 RS05 参数

请尽量从说明书、卖家页面或上位机软件里确认：

```text
1. 额定电压
2. 峰值电流
3. 额定力矩
4. 峰值力矩
5. 最大输出转速
6. 减速比
7. 控制模式：是否支持 MIT 模式
8. CAN 波特率和协议
9. 电机 ID 设置方式
10. 位置零点设置方式
```

## 真实硬件建议

树莓派不要直接做高速闭环控制。推荐结构：

```text
树莓派
  负责：策略推理、状态记录、实验流程

电机驱动/电机内部控制器
  负责：电流环、速度环、位置环、力矩控制

编码器/电机反馈
  负责：角度、速度、电流反馈
```

倒立摆项目里，最开始建议先只控制底座旋转关节：

```text
shoulder_yaw = RS05 主动电机
pendulum_1   = 被动编码器
pendulum_2   = 被动编码器
```

等仿真和控制算法稳定后，再上真实硬件。
