# 二阶圆周倒立摆建模笔记

当前模型是一个简化的二级旋转倒立摆：

```text
主动关节：底座 yaw 旋转
被动关节：第一节摆杆
被动关节：第二节摆杆
```

零位定义：

```text
pendulum_1 = 0 表示第一节摆杆竖直向上
pendulum_2 = 0 表示第二节摆杆相对第一节竖直向上
```

因此 reward 里可以直接用：

```text
cos(pendulum_1)
cos(pendulum_2)
```

作为直立程度。

这个模型现在是学习用的初版，不等于真实机械参数。后续如果要对应真实硬件，需要补：

```text
连杆长度
连杆质量
质心位置
转动惯量
摩擦
电机力矩限制
编码器噪声
控制周期
```
