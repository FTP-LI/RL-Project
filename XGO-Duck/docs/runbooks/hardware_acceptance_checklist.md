# XGO-Duck实机部署验收表

当前已完成电脑端模型与官方关节映射预检。实物已装配，机械中位、IMU和飞智黑武士4Pro待现场验收。填写时保留套件类别、扩展板丝印、应用构建、原厂模型哈希、操作者与日期。[完整部署和遥控手册](xgo_duck_first_deployment_and_vader4pro.md) · [电脑端离线预检](../../records/hardware/deployment-preparation/essential-bundle-check.json)

| 步骤 | 现场通过条件 | 证据 |
| --- | --- | --- |
| 原厂运行时与通信 | 确认套件、扩展板与控制台构建匹配。托架支撑并确认卸力。连续30秒读取到15/15舵机与持续更新的IMU数据。 | 控制台截图和状态原始读回 |
| 舵机身份和机械中位 | 15个ID与实际安装位逐项匹配，尤其是颈部30和鸭嘴34。按所用构建流程写入中位，重启后完成读回。 | 逐舵机记录表及正侧面标定照片 |
| IMU标定 | 按该构建的参考方向静止采样。保存成功后复查重启与水平站姿时的读数。 | IMU参考姿态、保存提示与复测读数 |
| 原厂台架和地面 | 默认姿势稳定10秒。前后、左移右移、左右转向各完成3次短输入及回中。方向一致，回中结束运动，网页卸力按钮在支撑状态下动作正确。 | 全身录像、方向记录、测试前后电压 |
| 飞智黑武士4Pro | 托架上核对三条摇杆轴、实际卸力键、回中零指令和断联后状态。确认重新连接需要显式启用。测试时记录连接模式与实际识别名。 | 输入、断联及重连截图或短视频 |
| 原厂回退 | 能定位并校验原厂程序、权重和这台机器的配置备份。切回原厂后复核15/15、IMU、站姿和一次走停。 | 版本及哈希、复测结果 |

现场资料保存在`records/hardware/<日期>/`。优先核对[逐舵机记录表](../../configs/hardware/commissioning_record_template.csv)。若是11月1日上板记录中的同一块UNO Q，从已装程序的IMU反馈复查开始。[既有上板记录](https://github.com/FTP-LI/RL-Project/blob/b9d7f58fdde1b74e25ec82ebd78a75931ad61f91/XGO-Duck/bringup/2026-11-01/README.md)
