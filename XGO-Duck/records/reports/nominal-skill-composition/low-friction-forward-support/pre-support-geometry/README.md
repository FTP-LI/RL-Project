# 首次双足承重前的运动复算

沿用种子1257、足底摩擦0.8的四路共同释放数据。第110–160步每20ms重建一次保存姿态，覆盖13组原未准入与原准入配对，共5,304个状态。CPU回算与原CUDA足底接触标志在5,300个状态中两足均一致。机身和足底位置使用同一释放坐标系，前向由释放时机身左轴的水平投影确定。右足间隙取碰撞网格最低点到地面的高度。足底接触范围按当时生效的接触点计算，配对的接触边界统计使用两边均通过接触核对的读数。[冻结配置](../../../../../configs/experiments/nominal_low_friction_forward_support_geometry.json) · [逐路复算](analysis.json) · [命令与退出码](review-command.log)

## 承重前分歧

每项先计算13个配对的差值，再取中位数。差值按原未准入减原准入。首次双足承重仍按实际4ms法向载荷确认，几何与速度读最近一个不晚于该时点的20ms状态。

| 指标 | 父策略 | 父策略同权重复测 |
| --- | ---: | ---: |
| 释放后480ms右足间隙（mm） | +24.86 | +29.64 |
| 释放后480ms机身倾角（°） | +20.75 | +22.77 |
| 首次承重前约120ms质心前向速度（mm/s） | −90.75 | −143.69 |
| 首次承重前约120ms转正角速度（°/s） | −204.04 | −167.09 |

两遍父策略在释放后480ms都各有11/13对的未准入场景右足更高。以首次承重对齐后，两遍分别有11/13对的未准入场景质心前向速度更低。固定时点的足间隙和按承重对齐的速度共同将筛查范围前移至首次持续承重前。质心和碰撞网格来自仿真状态，后续若评估策略须复核实际观测能否提供触发条件。[原4ms载荷与完整动作原片](../README.md)

## 承重前多关节回放

在释放后360ms和420ms，分别在第一遍父策略的13组配对上复算各关节扭矩对转正加速度、右足最低处的垂向加速度及左足、头部载荷的局部影响。用这些响应拟合一组共享调整，每关节至多0.06N·m，调整绝对值之和至多0.16N·m。随后四路从各自同初态以原占空比和供电回放160ms，每个状态保留两遍原扭矩。两种候选实际到达约0.16N·m合计调整，累计988次固定状态求解及8,160步CPU物理回放。[冻结配置](../../../../../configs/experiments/nominal_low_friction_forward_momentum.json) · [逐场景调整、实测响应及保护](momentum-replay/analysis.json) · [回放日志](momentum-replay/replay-command.log)

| 调整起点 | 目标8个初态的最大转正增益（°） | 通过3°及同窗承重判据 | 两遍父策略原准入保护 |
| --- | ---: | ---: | --- |
| 释放后360ms | 0.70 | 0/8 | 11/13、12/13 |
| 释放后420ms | 1.99 | 0/8 | 11/13、13/13 |

420ms调整在8个目标初态均增加转正。第一遍父策略的两个原准入状态超出头部载荷增量要求，记录在逐场景回放中。两种调整均以短回放归档。

## 训练信号的归档检查

在释放后400–640ms取每20ms样本，将转正进度和右足接近地面的进度相乘后求均值。转正进度在75°至15°间映射至0–1，右足间隙在60mm至0mm间映射至0–1。按13组历史配对，父策略、父策略同权重复测、原奖励组与候选组的原准入排名更高的数量依次为11、11、10和10/13，每路门槛为12/13。两个持续失分目标在四路均有正向配对差。近期4秒归档中，历史配对两端仍呈原姿态结果的数量分别为9、10、8、8/13。随后用每条完整轨迹自身的第600步准入结果重做配对，采用相同信号和比例门槛。[固定窗口与公式](../../../../../configs/experiments/nominal_low_friction_pre_support_progress.json) · [四路逐对信号](progress-qualification/analysis.json)
