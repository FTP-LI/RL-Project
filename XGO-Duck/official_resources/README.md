It is not a fourth upstream repository. The preview includes USB camera/audio and gamepad support; ToF integration is not implemented in the archived version.

The published directories are complete **source trees at the listed commits**, not independent Git repositories. Upstream Git history is not part of these snapshots. `original_archive_kind`, `original_git_repository`, shallow status, available refs and historical object-integrity results in the manifest describe the initial archive operation.

## Archive inventory

- [source_manifest.json](source_manifest.json): source URLs, selected refs, commits, tree IDs, file counts, source paths, snapshot hashes and provenance.
- [manifests/](manifests/): size and SHA-256 for each of the **585 source files**. Git administrative files are excluded.
- [snapshots/](snapshots/): **4 original ZIPs** generated by `git archive`, each with a top-level source-directory prefix.
- [snapshots.sha256](snapshots.sha256): SHA-256 checksums for the ZIPs, relative to this folder.
- [.gitattributes](.gitattributes): disables text conversion, filters and keyword expansion for the archived source trees so checkout bytes match the manifests on Windows and Linux.

The source files total 119,819,182 bytes and the ZIPs total 82,757,466 bytes (202,576,648 bytes combined, before Git packing). ZIPs contain source files, not upstream Git history. No upstream source content was changed during publication.

On 2026-10-28, file manifests were normalized to UTF-8 with LF line endings and their own hashes in `source_manifest.json` were updated. Source-file hashes and ZIP hashes remained unchanged. Those same hashes are retained in this distribution.

## Restore on another computer

With Git installed, run:

```bash
git clone https://github.com/FTP-LI/RL-Project.git
cd RL-Project
```

The source trees, CAD/mesh files, supplied models, documents and ZIPs are now present in `XGO-Duck/official_resources/`. Existing XGO-Lite2 project documents and its planning snapshot are also included in the clone.

To verify every archived source file, every file manifest and every ZIP, run this PowerShell block from the RL-Project root:

```powershell
$archiveRoot = Join-Path (Get-Location) 'XGO-Duck/official_resources'
$archiveManifest = Get-Content -Raw -LiteralPath (Join-Path $archiveRoot 'source_manifest.json') | ConvertFrom-Json
$verifiedSourceFiles = 0
foreach ($source in $archiveManifest.sources) {
    $manifestPath = Join-Path $archiveRoot $source.file_manifest
    if ((Get-FileHash -Algorithm SHA256 -LiteralPath $manifestPath).Hash.ToLowerInvariant() -ne $source.file_manifest_sha256) {
        throw "File-manifest hash mismatch: $($source.name)"
    }
    $fileManifest = Get-Content -Raw -LiteralPath $manifestPath | ConvertFrom-Json
    if ($fileManifest.files.Count -ne $source.file_count) { throw "File-count mismatch: $($source.name)" }
    foreach ($file in $fileManifest.files) {
        $filePath = Join-Path (Join-Path $archiveRoot $source.local_path) $file.path
        if ((Get-Item -LiteralPath $filePath -ErrorAction Stop).Length -ne $file.size_bytes) { throw "Size mismatch: $filePath" }
        if ((Get-FileHash -Algorithm SHA256 -LiteralPath $filePath).Hash.ToLowerInvariant() -ne $file.sha256) { throw "Hash mismatch: $filePath" }
        $verifiedSourceFiles++
    }
    $snapshotPath = Join-Path $archiveRoot $source.snapshot.path
    if ((Get-Item -LiteralPath $snapshotPath -ErrorAction Stop).Length -ne $source.snapshot.size_bytes) { throw "ZIP size mismatch: $snapshotPath" }
    if ((Get-FileHash -Algorithm SHA256 -LiteralPath $snapshotPath).Hash.ToLowerInvariant() -ne $source.snapshot.sha256) { throw "ZIP hash mismatch: $snapshotPath" }
}
Write-Output "Verified $verifiedSourceFiles source files and $($archiveManifest.sources.Count) ZIP snapshots."
```

This restores the archived project files. Installed Python/WSL/CUDA environments, training runs, UNO Q system images and unrecorded hardware calibration are not included. Follow the project deployment plan to install and validate the runtime or training environment.

## Restore source trees from ZIPs offline

Once the clone or ZIPs and manifests are saved locally, upstream network access is unnecessary. After the verification block above, extract into a **new** directory:

```powershell
$restoreRoot = Join-Path (Get-Location) 'restored_sources'
if (Test-Path -LiteralPath $restoreRoot) { throw 'Destination already exists; choose a new folder.' }
New-Item -ItemType Directory -Path $restoreRoot -ErrorAction Stop | Out-Null
foreach ($source in $archiveManifest.sources) {
    Expand-Archive -LiteralPath (Join-Path $archiveRoot $source.snapshot.path) -DestinationPath $restoreRoot -ErrorAction Stop
}
```

Each ZIP already contains its source-directory prefix. Extraction does not overwrite the tracked archive. To obtain upstream Git history for development, clone the relevant official repository into a separate working directory and check out the pinned commit; that optional operation depends on upstream availability.

## Local Git metadata preservation

On the original workstation only, the three former `.git` directories were preserved under `.upstream_git/<repository>.git`. That directory is ignored and is **not uploaded**. It contains local Git history/configuration and is not needed to restore any source file or ZIP. The archive paths themselves contain no nested `.git` directories or gitlinks.
