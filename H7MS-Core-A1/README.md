# H7MS-Core-A1

`H7MS-Core-A1`是面向机器人实时控制和小型强化学习策略推理的通用H7核心板。它不是电机功率板，也不绑定某一种机器人；第一块配套底板暂定为`H7MS-XGOBase-A1`，用于XGO Lite2舵机总线、电源与线束适配。

## A1设计边界

### 核心板固定资源

- MCU：`STM32H743VIH6`，TFBGA100，最高480 MHz。
- 时钟：8 MHz CMOS有源晶振，HSE Bypass；LSE预留可DNP。
- 电源：接收底板`BASE_5V`，板上产生3.3 V；USB 5V具有防反灌路径。
- 传感：SPI IMU、IMU加热MOSFET和NTC温度采样。
- 存储：QSPI NOR Flash和四位SDMMC TF卡。
- 调试：USB-C Device、5点SWD、NRST和BOOT0。
- 人机接口：单颗WS2812类RGB、蜂鸣器MOSFET接口。
- 实时扩展：4路串行执行器总线、2路CAN-FD逻辑、UART、I²C、SPI、ADC、TIM1和TIM2。
- 连接：`J1 + J2`两只50Pin板对板连接器，信号、电源和地对称分布。

### 必须放在底板

- 电池输入、保险、反接、TVS、浪涌和急停断电。
- 电池到5V的降压电源，以及电池电压/电流模拟前端。
- 舵机、CAN-FD等物理层收发器和机器人专用接插件。
- 执行器电源开关与大电流布线。
- 底板身份EEPROM和能力描述。

执行器大电流不能经过核心板或板对板连接器。

## 投板闸门

- CubeMX使用精确料号复查全部引脚、AF、DMA和时钟树。
- 关闭RGB和IMU加热共用TIM8的配置问题，记录两路信号同时工作的证据。
- 按最新数据手册、参考手册、勘误和硬件指南复核。
- 冻结连接器具体料号、板间高度、方向、安装孔和Keepout。
- 核对5V预算、USB/底板双电源切换、反灌、上电和掉电行为。
- 对IMU加热进行限功率、失控加热和温漂验证。
- 对TF卡、QSPI和IMU同时DMA运行进行Cache一致性和带宽测试。
- 使用无执行器底板完成所有安全输入的故障注入后，才允许连接实机。
