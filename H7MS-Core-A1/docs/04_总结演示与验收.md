# H7MS-Core-A1总结演示与验收

## 演示1：核心板Bring-up

- 限流上电与各电源波形。
- 480 MHz时钟、SWD和最小固件。
- USB枚举、IMU数据、加热闭环与NTC故障保护。
- QSPI模型区和TF卡挂载、写入、拔卡恢复。
- RGB、蜂鸣器、复位和BOOT0。
- 展示CubeMX配置、BOM和生产文件版本。

通过标准：连续运行无异常复位，电源与时钟满足设计值。

## 演示2：安全状态机

- 无底板、错误底板、急停未释放和电源故障时保持`SAFE_OFF`。
- 正常进入`READY/ACTIVE`。
- 注入上位机超时、IMU异常和`BASE_FAULT_N`。
- 故障后执行器使能撤销，且不能直接恢复到`ACTIVE`。

通过标准：所有状态转换与文档一致，并有时间戳日志。

## 演示3：单舵机台架

- 展示实测总线电平、波特率和数据包。
- 读取ID与状态。
- 小角度位置、停止和卸载。
- 连续运行、拔线、CRC错误和超时恢复。

通过标准：无总线争用、意外写配置和不可控输出。

## 演示4：整机接管

- 原厂与Core-A1物理互斥切换。
- 全关节状态和IMU同步上报。
- 悬空关节扫描、支撑架站立和地面低速运动。
- 上位机断联、急停和单舵机离线。
- 原厂链与Core-A1链时延、抖动和错误率对比。

通过标准：Core-A1安全行为不弱于原厂，可恢复原装线束。

## 演示5：H7本地策略

- 展示Actor从ONNX到H7生成代码的版本与哈希。
- 固定观测集对比PC和H7输出误差，并展示最坏推理耗时。
- Core-A1执行NaN/Inf检查、限位、变化率限制和策略超时。
- 同一策略先在回放器、再在悬空和低速真机运行。
- 展示一次故意越界动作被安全层拒绝。

通过标准：策略无法绕过Core-A1安全状态机，故障时回退，日志可还原最终发送到关节的命令。

## 完成定义

- Core-A1和XGO底板生产资料可复现。
- J1/J2针序、电源预算、机械叠高和连接器方向均有受控版本。
- 固件、上位协议、SDK、参数和故障码有版本。
- 单舵机和整机测试都有原始波形与日志。
- 原厂恢复路径经过实际验证。
- 未确认的力矩控制、FOC或CAN关节能力不写入完成声明。
