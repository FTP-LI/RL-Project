# H7MS-Core-A1固件架构

## 1. 分层

```text
Application
  安全状态机、运行模式、命令调度、故障管理
Policy
  观测构建、归一化、RL推理、动作后处理
Control
  状态估计、目标插值、限位和传统控制回退
Services
  时间、日志、参数、模型管理、升级、底板识别
Drivers
  IMU、加热、QSPI、SDMMC、USB、UART、CAN、ADC
HAL/LL
  STM32H7外设、DMA、Cache和中断
```

舵机协议、机器人关节定义和策略网络必须解耦。同一套BSP应允许切换`上位机动作、H7本地策略、传统控制、安全停机`四种运行方式。

## 2. 实时任务基线

| 任务 | 初始频率 | 说明 |
| --- | ---: | --- |
| 硬件安全检查 | 1 kHz | 急停、故障、电源和看门狗最高优先级 |
| IMU采样 | 1 kHz | SPI DMA + 数据就绪中断 |
| IMU恒温 | 100 Hz | PID/PI、输出限幅和传感器故障检测 |
| 状态估计 | 500 Hz | 姿态、偏置和有效性 |
| 本地RL策略 | 100～500 Hz | 根据模型耗时和执行器带宽确定 |
| 关节通信 | 100～250 Hz | 舵机总线版本受总线带宽限制 |
| 上位机命令 | 50～100 Hz | 命令带序号和有效期 |
| 状态上报 | 100 Hz起 | 不阻塞控制周期 |
| TF日志写入 | 后台批量 | 双缓冲，不在实时线程等待文件系统 |
| 慢速诊断 | 1～10 Hz | 电池、温度、统计和版本 |

所有任务报告平均周期、最大/P99抖动、超时、栈水位、CPU占用和DMA错误。

## 3. 安全状态机

```text
SAFE_OFF
  │ 底板识别、急停释放、无故障
  ▼
INIT
  │ IMU、总线、参数和策略校验通过
  ▼
READY
  │ 收到带有效期的使能命令
  ▼
ACTIVE
  │ 超时/急停/过温/欠压/总线或策略故障
  ▼
FAULT
  │ 故障消失且收到明确复位
  └────────────→ SAFE_OFF
```

策略层不能直接操作GPIO、电源使能或总线DMA。它只能提交动作数组，由安全层完成NaN/Inf、关节范围、动作变化率、姿态和通信有效性检查。

## 4. 内存与DMA约束

- ITCM：高频中断和关键控制代码。
- DTCM：控制状态、策略输入输出等CPU私有热数据；DMA不能直接访问DTCM。
- AXI SRAM：DMA缓冲、神经网络激活区和大块工作区。
- D2/D3 SRAM：外设DMA缓冲与跨任务邮箱。
- QSPI：只读模型权重、参数与回退镜像；进入实时模式前完成校验。
- TF：日志与采集数据，使用预分配文件和双缓冲。

启用D-Cache后，所有DMA缓冲必须按Cache line对齐，并在所有权切换时执行正确的Clean/Invalidate；不能依赖偶然一致。

## 5. 存储内容

| 存储 | 内容 |
| --- | --- |
| 内部Flash | Boot、主固件、最小恢复策略 |
| QSPI | 当前策略、回退策略、归一化参数、标定和故障快照 |
| TF卡 | 长日志、轨迹数据、更新包和测试报告 |
| 底板EEPROM | 板型、硬件版本、能力位和底板校准 |

策略包至少包含：魔数、格式版本、模型版本、硬件兼容版本、输入/输出维数、控制频率、关节顺序、归一化参数、权重长度和CRC/哈希。

## 6. 上位机协议

帧包含：魔数、协议版本、消息类型、长度、序号、时间戳、负载和CRC。首版消息：

- `HELLO/CAPABILITIES`
- `ENABLE/DISABLE/ESTOP`
- `JOINT_COMMAND`
- `ROBOT_STATE`
- `POLICY_SELECT/POLICY_STATUS`
- `DIAGNOSTICS`
- `PARAM_READ/PARAM_WRITE`
- `LOG_CONTROL`
- `BOOTLOADER_REQUEST`

未知消息、版本不匹配、CRC失败和过期动作不能改变执行器状态。

## 7. 开发顺序

1. 时钟、MPU/Cache、GPIO、SWD和Fault Handler。
2. USB控制与日志、内部Flash恢复路径。
3. IMU、时间戳、NTC和加热闭环。
4. QSPI模型区与TF卡后台日志。
5. 安全状态机和底板模拟器。
6. UART/CAN/I²C/SPI底板驱动。
7. 单执行器台架和多总线调度。
8. PC端策略回放与H7数值一致性。
9. H7本地策略推理及超时回退。
10. 整机分级接管。

## 8. 最低测试集

- 协议、归一化、动作后处理和状态机单元测试。
- ONNX参考输出与H7输出逐样本比较。
- DMA/Cache、TF拔出、QSPI校验失败和日志满故障注入。
- IMU中断丢失、NTC开短路、加热MOSFET失控检测。
- 急停、欠压、上位机断联、舵机离线和策略超时。
- 每次发布保存源码提交、`.ioc`、模型哈希、固件二进制和测试报告。
